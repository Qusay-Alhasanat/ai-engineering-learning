# Local Record Manager

A simple command-line application built with Python to manage records locally using JSON file storage.

## Overview

Local Record Manager allows users to create, view, search, update, and delete records through an interactive command-line interface.

The project focuses on practicing Python fundamentals, modular code organization, file handling, data validation, error handling, and automated testing.

## Features

- Add new records with automatically generated IDs.
- List all saved records.
- Find records by ID.
- Update individual record fields.
- Delete records by ID.
- Validate record titles and statuses.
- Persist data between application runs using JSON.
- Handle missing files and invalid JSON data.
- Validate loaded records and reject duplicate IDs.
- Run automated tests using pytest.

## Record Structure

Each record contains the following fields:

| Field | Description |
| --- | --- |
| `id` | Unique positive integer generated by the application. |
| `title` | Required, non-empty title. |
| `description` | Optional text description. |
| `status` | One of `pending`, `in_progress`, or `completed`. |

New records are assigned the `pending` status by default.

## Installation

Clone the repository and navigate to the project directory.

Synchronize the project environment and install its development dependencies:

```bash
uv sync
```

## Usage

Start the application:

```bash
uv run python -m local_record_manager.main
```

The application displays an interactive menu:

```text
=== Local Record Manager ===
1. Add record
2. List records
3. Find record
4. Update record
5. Delete record
0. Exit
```

Choose an option and follow the prompts.

Records are stored locally in `records.json` and remain available when the application is restarted.

## Running Tests

Run the automated test suite:

```bash
uv run pytest -v
```

The tests cover record operations, input validation, data persistence, and error handling.
